# robotframework-fhir

A Robot Framework keyword library for testing **FHIR R4** health-data servers, with its
keyword documentation, acceptance suites on lab results, and a CI that runs them
against a real HAPI FHIR server.

Built with Claude Code.

## The library

`FhirLibrary` (Python) gives Robot Framework 15 keywords:

| Area | Keywords |
|---|---|
| Connection | `Connect To FHIR Server` (checks `/metadata` returns a CapabilityStatement) |
| Resources | `Load Resource`, `Create Resource`, `Read Resource`, `Update Resource`, `Delete Resource`, `Resource Should Not Exist` |
| Search | `Search Resources` (returns the Bundle entries as a list) |
| Validation | `Resource Should Be Valid`, `Resource Should Be Invalid` (server `$validate`, OperationOutcome errors) |
| Clinical checks | `Observation Should Be Within Reference Range`, `Observation Should Be Outside Reference Range` |
| Assertions | `Get Resource Value`, `Resource Value Should Be` (dotted paths: `code.coding[0].code`), `Status Should Be` |

Full documentation, generated by `libdoc`: [`docs/FhirLibrary.html`](docs/FhirLibrary.html),
also published to GitHub Pages by the CI.

```robotframework
*** Settings ***
Library    FhirLibrary

*** Test Cases ***
High Glucose Is Flagged
    Connect To FHIR Server    http://localhost:8080/fhir
    ${obs}=    Load Resource    tests/data/glucose_high.json
    ${obs}=    Create Resource    ${obs}
    Observation Should Be Outside Reference Range    ${obs}
```

## Acceptance suites

`tests/` holds three suites, each test tagged with the requirement it covers
(`requirements.csv`):

- **patient.robot**: create, read, search by family name, update (new version), delete.
- **observation.robot**: glucose results (LOINC 2345-7) inside and outside their reference
  range, search by patient and LOINC code.
- **validation.robot**: a conformant Patient and a lab Observation pass `$validate`; a Patient
  with an invalid gender code is rejected.

## Run it

```bash
docker run -d --name fhir -p 8080:8080 hapiproject/hapi:v7.6.0
pip install -e ".[dev]"
pytest -q                                   # unit tests of the helpers
robot --outputdir results tests             # acceptance suites
libdoc FhirLibrary docs/FhirLibrary.html    # keyword documentation
```

## CI

GitHub Actions (`.github/workflows/ci.yml`):

1. **unit**: pytest, then the keyword documentation with `libdoc`.
2. **acceptance**: a HAPI FHIR server as a service container, the Robot Framework suites,
   then [qa-report-kit](https://github.com/AbdelkbirNA/qa-report-kit) as a quality gate:
   100 % pass rate and every requirement in `requirements.csv` covered.
3. **pages**: publishes the keyword documentation.
